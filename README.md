# Travel E-commerce Website

A web-based travel booking platform where users can explore destinations, view travel packages, make bookings, and manage their trips efficiently.

## Features
- User Registration and Login
- Browse Travel Packages
- Search and Filter Destinations
- Booking Management
- Secure Payment Integration
- Responsive Design
- Admin Dashboard

## Technologies Used
- Frontend: HTML, CSS, JavaScript / React
- Backend: Java / Spring Boot
- Database: MySQL
- Version Control: Git & GitHub
